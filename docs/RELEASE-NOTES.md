First public release of **Artilody Sampleforge** for macOS, Windows and Debian/Ubuntu Linux.

Turn a recording of notes played one by one in ascending chromatic order into a tuned SFZ 1.0 instrument with 24-bit WAV samples.

### Downloads

| System | File |
|---|---|
| macOS 11+ (Apple Silicon & Intel, universal) | `Artilody-Sampleforge-0.2.0-macOS.dmg` |
| Windows 10/11 x64 - installer | `Artilody-Sampleforge-0.2.0-Windows-x64-Setup.exe` |
| Windows 10/11 x64 - portable | `Artilody-Sampleforge-0.2.0-Windows-x64-Portable.zip` |
| Debian 12+ / Ubuntu 22.04+ (amd64) | `artilody-sampleforge_0.2.0_amd64.deb` |
| Other Linux x86_64 | `artilody-sampleforge-0.2.0-linux-x86_64.tar.gz` |
| Manuals | `Artilody-Sampleforge-Manual-EN.pdf`, `Artilody-Sampleforge-Manual-DA.pdf` |

Linux: `sudo apt install ./artilody-sampleforge_0.2.0_amd64.deb`

**First launch:** the builds are not signed with paid certificates. On macOS use *System Settings > Privacy & Security > Open Anyway*; on Windows click *More info > Run anyway* in SmartScreen. See the manual for details.

### Highlights

- Native C++20 / JUCE 8 application, works fully offline
- Automatic onset detection and chromatic note mapping with gap detection
- Pitch measurement, per-sample tuning suggestions, original/corrected preview
- Trim, split and merge samples
- Fixed 88-key keyboard overview (A0-C8)
- SFZ 1.0 + 24-bit WAV export as folder or ZIP
- English and Danish PDF manuals; installer in English and Danish
